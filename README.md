# GamePoint Console

Sistema web inspirado em menu de console, pronto para GitHub Pages.

### Inclui
- Tela de inicialização
- Seleção de usuário
- Menu Início / Loja / Biblioteca / Downloads / Configurações
- Detecção de Gamepad
- Loja com pesquisa
- Botão Jogar
- Botão Baixar
- 3 jogos HTML5 incluídos: Flappy Sky, Click Master e Neon Runner

### Adicionar outro jogo
Crie `games/nome/index.html` e cadastre no array `games` em `app.js`.

### GitHub Pages
Envie os arquivos para um repositório e ative Settings > Pages > Deploy from a branch > main > root.
